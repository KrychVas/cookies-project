# Cookies Project 🍪

A clean, modern, and pixel-perfect landing page developed as part of a practical masterclass to master professional web layout techniques.

🔗 **Live Demo:** [View the Project Live](https://krychvas.github.io/cookies-project/)

---

## 📝 Project Description
This project was built step-by-step following professional developer guidance to understand real-world frontend workflows. The main focus was on turning a design concept into a clean, well-structured, and cross-browser compatible webpage, ensuring that all layout elements line up perfectly.

## ✨ Features
* **Pixel-Perfect Layout:** Strict adherence to design proportions, spacing, and alignment.
* **Semantic HTML5:** Clean and meaningful markup for better accessibility and SEO.
* **Modern CSS Techniques:** Advanced use of CSS positioning, custom fonts, and styling methods.
* **Cross-Browser Compatibility:** Tested to ensure smooth rendering across all modern web browsers.

## 🛠 Tech Stack
* **HTML5:** Structuring the content and layout.
* **CSS3:** Custom styling, typography, and visual assets management.

## 📁 Project Structure
The repository is organized following standard development practices:
* `/fonts` — Custom typography assets.
* `/images` — Optimized visual graphics and icons.
* `/scripts` — JavaScript files for future interactivity.
* `/styles` — Modular CSS files for styling.
